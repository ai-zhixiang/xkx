## 二、各环节详细设计

### ① 排期调度器

**触发方式：** cron 脚本（享客虾服务器，139.155.158.18）

```
每天 08:00 → 触发当日内容生成
每天 09:00 → Bot 推送「今日内容已生成，请审核」
每天 12:00 → 未审核的内容自动过期提醒
```

**排期定义（用户在 Bot 对话中设定）：**
```
用户：帮我安排这一周的小红书内容
Bot：好的，请告诉我每天的主题
用户：周一旅行穿搭，周二护肤，周三美食探店，周四职场干货，周五周末好物
Bot：已记录！每天 08:00 自动生成，09:00 推送到你这
```

**数据存储：**
```json
{
  "user_id": "xxx",
  "schedule": [
    {"day": "mon", "topic": "旅行穿搭", "style": "活泼"},
    {"day": "tue", "topic": "护肤", "style": "文艺"},
    {"day": "wed", "topic": "美食探店", "style": "简约"},
    {"day": "thu", "topic": "职场干货", "style": "商务"},
    {"day": "fri", "topic": "周末好物", "style": "活泼"}
  ],
  "publish_type": "manual_review",  // manual_review | auto_publish
  "enabled": true
}
```

### ② 选题引擎

当排期触发但用户未指定具体主题时，AI 自动生成选题：

```
输入：旅行穿搭（周一）
输出建议：
  「沙漠OOTD | 防晒又出片」
  「行李箱开箱 | 短途旅行必备5件」
  「酒店拍照姿势 | 拯救镜头尴尬症」
Bot 推 3 个选题给用户选，或直接选第一个
```

**数据来源：**
- 小红书当前热点（通过联网搜索爬取趋势词）
- 用户历史内容（分析账号定位）
- 季节/节日（自动适配：夏天推防晒、冬天推保暖）

### ③ 文案生成引擎

**提示词模板：**
```
你是一个小红书内容创作者。根据以下要求写一篇小红书笔记：

主题：{topic}
风格：{style}
字数：200-300字
结构：标题（带emoji）→ 导语 → 正文(3-4个要点带emoji) → 总结 → 标签

要求：
- 口语化、姐妹感
- 用 emoji 分段
- 有个人体验感
- 标签5-8个
```

### ④ 封面合成管线

**复用已有能力：**
- 享客虾评封面管线（PIL 1200×630 → 适配 3:4 为 900×1200）
- 豆包 Vision 生成背景图
- 5 种风格预设（简约/文艺/商务/活泼/国潮）

**新增模板参数：**
```python
{
  "width": 900,
  "height": 1200,        # 3:4 竖版
  "style": "活泼",
  "title": "沙漠OOTD",
  "subtitle": "防晒又出片",
  "tags": ["穿搭", "旅行"],
  "bg_type": "solid|gradient|image|pattern",
  "text_color": "#ffffff",
  "accent_color": "#ff6b6b"
}
```

**产出：** 3-5 张备选封面图（JPG），用户选一张或驳回重生成

### ⑤ Bot 推送审核

**每天 09:00 推送格式：**
```
📋 今日内容已生成（3篇）
━━━━━━━━━━━━━━━━━
① 沙漠OOTD | 防晒又出片 ✅ 已确认
② 行李箱开箱 | 短途必备5件 ⏳ 待审核
  - 点击查看封面 → [图片]
  - 回复「确认②」通过
  - 回复「重做② 换个风格」重新生成
③ 酒店拍照姿势 ⏳ 待审核
━━━━━━━━━━━━━━━━━
回复「全部确认」一键通过
回复「全部发布」直接发布
```

**审核状态流转：**
```
待审核 → 用户确认 → 已确认（待发布）
待审核 → 用户驳回 → 重新生成（进入排队）
待审核 → 12:00未处理 → 自动转为草稿
```

### ⑥ 一键发布到小红书

**前置条件：**
- 用户在小红书开放平台创建应用
- 用户授权（OAuth）享客虾获取 token
- token 有效期管理（refresh_token 每30天刷新）

**发布方式：**
```python
# POST https://openapi.xiaohongshu.com/api/note/publish
{
  "title": "沙漠OOTD | 防晒又出片",
  "content": "正文...",
  "images": ["封面URL1", "封面URL2"],
  "topic_ids": ["旅行", "穿搭"],
  "location": "腾格里沙漠",
  "publish_time": "2026-07-04 10:00:00"  # 定时发布
}
```

**注意事项：**
- 每日发布限额（个人号通常 10 条/天）
- 图片需先上传到小红书 CDN
- 敏感词检测（发布前自动过审一遍）
- 失败重试 + 通知用户

## 三、实现路线

### Phase 1：Bot 对话式生成（Week 1-2）

目标：用户在 Bot 说「写一篇小红书」→ 出文案+封面

| 任务 | 技术 | 依赖 |
|------|------|------|
| 小红书 prompt 注入 Bot | DeepSeek 提示词 | 无 |
| 封面生成 API | PIL + Pollinations | 现有的封面管线 |
| Bot 回复图文 | 现有的 Bot send/Media | 无 |

### Phase 2：排期+批处理（Week 3-4）

目标：用户设定一周排期→自动每天出内容

| 任务 | 技术 | 依赖 |
|------|------|------|
| 排期存储 | weclawd DB 加 schedule 表 | Phase 1 |
| cron 调度器 | 享客虾服务器 crontab | — |
| Bot 晨间推送 | keepalive send API | — |
| 多篇审核/批量确认 | Bot 交互流程 | Phase 1 |

### Phase 3：一键发布（Week 5-6）

目标：接入小红书开放平台，用户确认后直发

| 任务 | 技术 | 依赖 |
|------|------|------|
| 小红书 OAuth 接入 | OAuth 回调流程 | 小红书开发者账号 |
| 发布 API 封装 | HTTP 客户端 | Phase 2 |
| token 管理 | refresh_token 持久化 | — |
| 发布状态回调 | webhook | — |

### Phase 4：AI 选题+竞争分析（Week 7-8）

目标：AI 自动选题、分析竞品、优化内容策略

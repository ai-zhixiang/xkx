## 一、产品概述

### 定位
享客虾 Bot 的一个垂直 Skill——微信对话式生成小红书笔记内容（文案 + 封面图），目标用户为小红书运营者、博主、企业代运营团队。

### 核心价值
| 痛点 | 解决方案 |
|------|----------|
| 写笔记花 2 小时/篇 | AI 生成文案+封面，10 分钟定稿 |
| 封面图不会做 | AI 自动配图+排版+文字，3:4 比例自动适配 |
| 排版丑、没人点 | 风格可选（简约/文艺/商务/活泼），AI 自适应 |
| 不会选题 | AI 根据热点+账号定位推荐选题 |

### 与 QClaw 的差异优势
- **交互方式**：微信 Bot 对话式，比网页工具门槛更低
- **能力整合**：享客虾已有 AI 写作+视觉+Bot 三件套，非单一功能
- **生态联动**：生成的内容可一键做成嗨卡/MV，跨平台复用
- **变现灵活**：虾点计费 + 套餐订阅 + 高阶代运营

## 二、用户场景

### 场景 1：个人博主日常更新
> 用户打开享客虾 Bot →「帮我写篇小红书，主题是沙漠旅行穿搭，活泼风格」→ Bot 出文案+3 张封面备选 → 用户选一张微调 → 导出发布

### 场景 2：企业代运营批量产出
> 运营每周一给 Bot 发一周选题 → Bot 自动排期 → 每天按时间线生成笔记 → 运营审核后一键发布

### 场景 3：爆款模板售卖
> 用享客虾生成 100 套小红书封面模板 → 打包定价 99 元 → 在小红书/抖音销售（零边际成本）

## 三、功能设计

### 3.1 对话式笔记生成

用户在 Bot 输入简单的创作意图，AI 自动补全完整内容：

**输入：**
```
帮我写篇小红书
主题：沙漠旅行穿搭
风格：活泼
要点：防晒、出片、ootd
```

**输出（Bot 回复）：**
```
📝 标题：沙漠OOTD | 防晒又出片！穿对了两千拍出两万效果

正文：
姐妹们！！去了趟腾格里沙漠我终于明白了
为什么说沙漠是穿搭界的照妖镜 👀
穿对了你是时尚博主，穿错了你是逃难的

🏜️ 沙漠穿搭三大铁律：
1. 红色/白色最出片，黑色别穿（吸热+显矮）
2. 防晒衣选冰丝款，别穿冲锋衣（拍照臃肿）
3. 靴子！靴子！靴子！别穿凉鞋（一脚沙）

💄 妆容tips：
- 定妆喷雾必须带（沙漠大风分分钟吹花）
- 口红选红棕色系，阳光下绝美
- 防晒每隔2小时补一次（别问我怎么知道的）

💰 省流：优衣库防晒衣199 + ZARA靴子399 = 出片王炸
沙漠穿搭天花板就是这个组合！

#沙漠穿搭 #旅行ootd #一衣多穿 #沙漠旅游
```

**封面图（同时生成，3 张备选）：**
- 方案A：沙漠背景 + 红色连衣裙 + 大标题「沙漠穿搭天花板」
- 方案B：局部特写 + 穿搭九宫格 + 「防晒又出片」标签
- 方案C：沙漠日落剪影 + 白色文字「穿对了沙漠=时尚大片」

### 3.2 封面图生成引擎

| 功能 | 实现方式 |
|------|----------|
| 比例适配 | 自动生成 3:4 竖版（小红书标准），无需用户调整 |
| 多风格模板 | 简约/文艺/商务/活泼/国潮 5 种预设风格 |
| 文字自动排布 | 标题+副标题+标签，AI 根据背景色自动调整字体颜色和大小 |
| 批量备选 | 每次生成 3-5 张，用户选中后微调 |
| 素材库 | 缓存历史生成的优质模板，支持复用 |

### 3.3 批量/排期模式

- **周排期**：周一输入一周主题，Bot 每天按排期产出
- **批量生成**：一次性生成多条笔记草稿，用户在 Bot 内预览挑选
- **内容日历**：Bot 内建日历视图，可视化排期（v2 功能）

### 3.4 AI 选题推荐

- **热点追踪**：Bot 联网搜索当前小红书热点话题，推荐选题
- **账号诊断**：用户提供账号链接，AI 分析历史内容给出优化建议（v2 功能）
- **竞争分析**：输入竞品账号，AI 分析其爆款规律（v2 功能）

## 四、技术方案

### 4.1 架构图

```
用户微信 → 享客虾 Bot (Bot Gateway)
              ↓
         意图识别（L0: 小红书创作话题？）
              ↓
          ├── 文案生成 ← DeepSeek v4-flash（已有）
          ├── 封面生成 ← 豆包 Vision + Pollinations
          └── 排版合成 ← PIL（已有的封面管线）
              ↓
         Bot 回复（文字 + 图片）
```

### 4.3 新增模块

## 六、自动发布管线

### 6.1 管线设计

```
触发器 → 内容生成 → 封面合图 → Bot 审核 → 用户确认 → 导出/发布
```

### 6.2 三种发布模式

| 模式 | 流程 | 适用场景 |
|------|------|----------|
| A：Bot 对话出稿 | 用户聊→Bot 生成→Bot 回复图文→用户长按保存 | 个人博主日常 |
| B：排期自动产 | 用户设定一周选题→Bot 每天出→用户晨间审核 | 企业代运营 |
| C：API 输出 | 第三方通过 API 调享客虾小红书引擎 | 平台合作/嵌入 |

### 6.3 导出格式

- **图文**：文案纯文本 + 封面图（3:4 JPG）
- **草稿链接**：生成小红书草稿页 URL（用户打开即可发布）
- **一键发布**：通过小红书开放平台 API 直发（需接入，v2 功能）
